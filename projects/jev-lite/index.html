What this actually is

A logistic model over 12 lexical features, trained by distillation on 126 live measurements from the real Typesafe.ai JEV oracle. The weights, the corpus, the split and the training script are all shipped. Re-run collect.py with a key and you get the same corpus back. It is a distillation of a real instrument — not a stub, and not a lookup table: it ranks claims it has never seen.

It is not the oracle. It is limited, and the limits are measured rather than asserted.

Known-answer control

A model that returns a number is not an instrument. An instrument has been shown to return the right number on a case where the right number is already known. These are the cases the model was gated on, running here, in your tab.

Where it stops

Held out 25%, stratified by band, seed fixed, never trained on:

The honest limit. A vague claim and a false claim are not separated — and the oracle it was distilled from does not separate them either (means 0.161 vs 0.176, ranges overlapping almost entirely). Both fail the same test: they are not checkable claims. So this instrument has two categories, not three, and a three-way one would be a lie.
