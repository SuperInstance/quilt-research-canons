  BACKEND: CPU  -- FALLBACK: torch not installed

  REFUTED   A content matcher can be trusted to notice that a periodic scene changed.
  It cannot. On a texture with period p there are p exact matches available and
  nearest-first search takes the first one, so the reported cost approaches zero
  while the true cost is 1.0. The escape is a MOTION VECTOR, not a better search:
  a displacement is unambiguous on a periodic texture, a nearest match is not.
