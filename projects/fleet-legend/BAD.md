# bad-repo

A project for exploring things and related matters.

This paragraph exists so the length heuristics in the linter genuinely engage rather
than short-circuiting on a short document. Without enough prose here the later
obligations would be skipped entirely and the fixture would be testing nothing, which is
itself the failure mode this whole toolkit is built to detect.

It describes an approach in general terms without giving anyone a command to run, and it
makes no claim about what the project produces or how you would know whether it worked.
