five predictions were wrong and the account is better than I said in three separate
places.** Recording that before anything else, because the alternative — quietly
re-reporting the numbers that suited the thesis — is exactly the failure this whole
discipline exists to prevent.

## The enumeration itself is a finding

**`/users/SuperInstance/repos` enumerates 1,300 repos. The profile claims 4,856.**

That gap is 3,556 repos. They are not deleted — the profile count includes repos that
are private, unlisted, or otherwise not returned to an unauthenticated-ish enumeration.
Whatever the reason, **the public, enumerable surface is about a quarter of the claimed
count**, and every number in every audit written today is drawn from that 1,300.

This is the same shape as the "0 of 10 externally decidable" finding. The account is
larger than the part of it that can be seen.

## What this changes

The greater-SuperInstance read said the binding constraint is legibility, not quality.
That is now better evidenced than when it was written: the quality is not the problem and
never was. There are 42,937 source files and 15,958 test files and 33% of repos have CI.

The problem is narrower and uglier than "we need to explain ourselves better":

1. **Nobody knows what is in the account.** 1,300 enumerable of 4,856 claimed. A 30-file
   repo and a 6,000-file repo are both just rows in the same list. There is no index that
   distinguishes them, which is why the interesting ones have never been looked at.
2. **The interesting repos are invisible to the search that gets run.** Every scout this
   session searched by name prefix. `claw` does not start with `quilt` and therefore never
   appeared in a single query.
3. **The audits have been auditing the wrong layer.** This census, the attribution audit,
   the license sweep, and the receipt census all share a blind spot: they enumerated the
   visible 1,300 and reported on that as though it were the account.

The cheapest possible next step is not a new artifact. It is **an index that says which
of the 1,300 are worth attention, built from the file counts already computed here**, so
that the next scout starts from the top of that list instead of guessing prefixes.

## Carried forward

- **Do not prefix-search.** Search by file count, test count, and last push. `claw`,
  `hermes-construct`, `rune-quilt` and `quilt-crabbox` have never come up in a scout.
- **Re-derive every audit against this census** before trusting its denominator. Three
  audits in this canon are currently scoped to the visible quarter.
- The 3,556-repo gap is itself a question worth one round.
