## PR-sweep gotchas (cross-project)

- **Git push with token**: embed in remote URL: `https://x-access-token:${GITHUB_TOKEN}@github.com/...`. Plain `git push` fails on no-TTY ("could not read Username"). Git Data API requires the commit/objects to exist on remote first.
- **GH API mergeable state staleness**: when a PR was opened days ago against an older base, `mergeable` is `null` until GH re-computes. After a base update (or just waiting 1-2 sec), it refreshes. Don't trust `None` as "blocked".
- **Squash-merge commit title** is the PR title first line; the body is the PR description (use that to embed the receipted intent + local-verify table).
